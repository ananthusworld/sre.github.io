SLO & Alerting Quick Guide

  1. Define user journeys (e.g., API availability, checkout latency).
  2. Pick SLIs tied to user impact (success rate, p95 latency).
  3. Set SLO targets and error budget policies per service tier.
  4. Alert on burn-rate, not every failure event.
// Example multi-window burn-rate alert logic
const burnRate = errorRate / (1 - sloTarget);
if (burnRate > 14.4 && window === '5m') pageOnCall();
if (burnRate > 6 && window === '1h') createIncident();
